# The Console Adventure

**The Console Adventure** is a project created on May 16 2024.
This game should be a *RPG*.

## Game features
Currently this game supports features like:
> Create new, Save/Load World
>
> Building
> 
> Write, Download and Use Mods
> 
> Multiplayer (in progress)
> 
> Craft items
> 
> Craft Book
> 
> Mine in caves
> 
> and much more )
